# Sobre o projeto HealthUp

Se originou de um projeto de fim de ano em grupo da disciplina de Projeto Integrador I. O site deveria abordar temas sobre uma vida saudável, e o nosso grupo escolheu o tema de Exercícios Físicos (dentre os temas pré-definidos pelo professor). O objetivo do projeto era unificar conhecimentos absorvidos das disciplinas de Desenvolvimento Web I, Lógica de Programação I e Introdução à Computação.

O site foi construído usando apenas HTML, Javascript e CSS. Mas para uma *feature* que necessitava de um *backend*, foi optado Node.js.
